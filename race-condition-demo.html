The Bug — Read-Modify-Write

// Both threads run this at the same time async function transfer(amount) { // 1. Both threads READ the same stale value const bal = account.balance; // e.g. 1000 // 2. Compute independently — no awareness of each other await sleep(delay); const next = bal - amount; // both compute 900 // 3. Both WRITE — second clobbers first! account.balance = next; // 900 (not 800!) // One transfer effectively never happened }

The Fix — Mutual Exclusion

// A simple promise-based mutex class Mutex { acquire() { /* waits for lock */ } release() { /* wakes next waiter */ } } async function transfer(amount) { await mutex.acquire(); // only one thread proceeds // Now safe — single thread in critical section const bal = account.balance; await sleep(delay); account.balance = bal - amount; mutex.release(); // next thread can enter }
