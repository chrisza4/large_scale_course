Cache Write Strategies

การเขียนข้อมูล การยืนยัน

Write-around

แอปพลิเคชันเขียนข้อมูลตรงไปยังที่ Source of truth โดยข้าม Cache ไป การอ่านจะอัพเดท Cache ตามหลักกลยุทธ์ฝั่ง Read

Write-through

การเขียนข้อมูลทุกครั้งจะไปที่ Cache แล้ว Cache จะบันทึกเข้า Source of truth ก่อน รอเสร็จทั้งสองฝั่งค่อยยืนยัน

Write-behind

การเขียนข้อมูลจะเขียนลง Cache แล้วยืนยันทันที รอไปซักพัก Cache จะ Flush ลง Source of truth
