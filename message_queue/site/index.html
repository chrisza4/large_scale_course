Message Queue Mythbuster

ข้างล่างเป็นเหตุผลที่คนนิยมใช้ในการเอา Message Queue เข้ามา ข้อในเป็นเหตุผลที่ใช่จริงๆ กับอันไหนที่ยังไม่ค่อยใช่เพราะมีทางเลือกอื่นที่ง่ายกว่านะ

วิธีเล่น: ในแต่ละข้อความ กรุณาเลือก Valid หรือ Not Valid พร้อมใส่คำอธิบายข้างล่าง เสร็จแล้วกดปุ่ม "เฉลย!" เพื่อดูว่าได้กี่ข้อ

ถ้ามีทางเลือกอื่นที่ไม่ใช่ Message Queue ที่ Simple กว่า ให้ถือว่า Not Valid เสมอ
